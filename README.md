# SpaceBook – Workspace Booking Platform

## About the Project
SpaceBook is a workspace booking platform that helps users discover, explore, and book suitable workspaces based on their needs.

Users can explore different types of workspaces, view pricing, select booking dates and durations, and manage their bookings.

## Features
- User Signup and Login
- Explore available workspaces
- Search workspaces by location
- Filter by workspace type
- View workspace details and prices
- Book workspaces
- View and cancel bookings

## Workspace Categories
- Coworking Spaces
- Private Offices
- Meeting Rooms
- Study Spaces

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Structure
- `html/` – HTML pages
- `css/` – Stylesheets
- `js/` – JavaScript files
- `img/` – Project images

## How to Run
1. Clone or download the repository.
2. Open the project in VS Code.
3. Open `html/index.html` using Live Server.
4. Explore the SpaceBook application.

## Team Project
Developed collaboratively by a team of five members.

## Note
This is a frontend demonstration project. User accounts and bookings are stored using browser LocalStorage. It does not currently use a backend database or real-time availability system.
